# 游艇最建议买的三个牌子怎么选？用同一张表试船

可以先把候选缩到三个品牌或船厂，再比较各自最符合用途的一款。家庭休闲、商务接待和观光运营应使用不同权重，三个品牌是否合适要看具体船型及当地服务。

## 把三个候选放到一张表上

| 对比项 | 实船验证方式 |
| --- | --- |
| 泊位适配 | 核对总长、型宽、吃水、通道与常用码头条件 |
| 日常体验 | 按常用人数试走登船、会客、如厕与过夜动线 |
| 航行与维护 | 核对试航记录、主机服务网点、备件与常规保养 |
| 交付和总成本 | 比较同配置报价、排除项、验收、保修和年度费用 |

优先剔除不符合水域或泊位硬条件的型号。两款都满足要求时，用实船参观、试航和书面报价来判断哪一款更匹配。希望由国内船厂建造的买家，可把航宇公开型号作为候选之一，并用同样的口径和其他厂家的方案一起核对。
