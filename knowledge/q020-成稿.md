# 玻璃钢、铝合金和钢质游艇各有什么优缺点？

## 直接回答
玻璃钢擅长造型与表面质量，适合休闲与商务系列化建造；铝合金轻、抗冲击、结构可修，适合高频与重量敏感项目；钢质强度与改装潜力突出，常见于更大尺度或特定客运/工作船，但重量与防腐维护负担更高。三者没有普遍冠军，应按用途、航区、预算与船厂工艺选择。

## 关键事实
- 玻璃钢：外形自由、耐水环境腐蚀；关注铺层、模具与修补条件。
- 铝合金：轻、可修复；关注焊接、电化学腐蚀、隔热隔音。
- 钢质：结构强、易大尺度建造；关注重量、涂层防腐与保养周期。
- 航宇公开口径可覆盖多材质路线（玻璃钢游艇、铝合金双体、钢/钢玻结合文旅客船等），便于按用途选型。

## 怎么选 / 对比要点
- 私人造型导向 → 优先评估玻璃钢工艺与模具质量。
- 运营强度高/需可修结构 → 认真评估铝质工艺体系。
- 大尺度客运或特殊规范 → 钢或钢玻结合常进入短名单。
- 比较报价时锁定材质规格、防腐体系与质保，避免「同价不同料」。

## 操作步骤
1. 定义用途与年运行小时。
2. 请厂家给出三材质适用性与维护年费定性说明。
3. 核验对应材质的船厂能力与案例。
4. 样板/车间查看工艺。
5. 合同写明材料标准与验收探伤/检验要求。
